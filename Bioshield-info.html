This was a project dedicated to how AI can be implemented in web development. A fictional bug extermination company, “Bio-Shield” requested a fully functional site for their products. The task was to see how AI would respond to certain prompts that it was given.

1. Resources

Languages: HTML5 and CSS3. Tools: AI chatbots such as ChatGPT for programming logic, and Adobe firefly for image generation, Visual Studio Code for development and Git/GitHub for version control. Deployment: Hosted via Netlify to ensure global accessibility and performance.

2. Skills I Acquired

AI Prompt Interpretation: I gave ChatGPT/firefly certain coding/imagery prompts, and documented based off of how it responded, and the final product itself. CSS Animations: I learned how to add visual, interactive effects, and animations to the various aspects of our site.

Basic Structure, and Style of a Website: I discovered how a basic informative website should look, and act, as well as how to spice up a site using CSS. This project was how I became acquainted with the language.

3. Problems Faced

The Problem: I couldn’t figure out how to stack multiple tags in the same space, or lay one object on top of each other. The Solution: After guidance from my Instructor, I realized that I could position a custom background image for a class in CSS considering the image is compatible in Aspect Ratio.

4. Mindfulness

Curiosity: Prior to this project I never Interacted with AI for some time, and I was skeptical about using it as a coding partner. Still, it turned out to be an extremely helpful tool. Optimism: While I wasn’t against AI, I was skeptical about it due to the self-handling nature of it. However, I strived to keep an open mind towards a challenge.

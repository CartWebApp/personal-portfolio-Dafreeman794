EECU required implementing their “Wise-Up” budgeting calculator into a digital form. As such, using Fetch()API, and Chart.js, I developed a site which incorporated a completely
automated taxation system, and a calculator regarding post-income necessities.

1. Resources

Languages: HTML5, CSS3, and Vanilla JavaScript.
Tools: Figma for detailed prototype creation, Visual Studio Code for development and Git/GitHub for version control.
Deployment: Hosted via Netlify to ensure global accessibility and performance.

2. Skills I Acquired

DOM Creation, and Management: Chart.js/Fetch(): I learned that the data utilized in algorithmic budget calculators such as this comes from a database made beforehand. I also learned how to customize, and document
a Pie chart using Chart.js.
LocalStorage saving: I learned that the proper data that needed to be saved was client-side connected.
